## Текст страницы `/delete-account`

**Как удалить аккаунт «Опоры»**

В приложении или на сайте: «Профиль» → «Удалить аккаунт» → введите подтверждение. Аккаунт и все данные удаляются сразу.

Если у вас нет доступа к приложению: напишите на ______@myopora.kz с адреса, на который зарегистрирован аккаунт, тему «Удалить аккаунт». Мы удалим его в течение 3 рабочих дней и ответим письмом.

**Что удаляется:** аккаунт, разговоры с ИИ, дневник, план, записи практик, сны и комиксы, настройки, подписки на уведомления, связь с психологом и записи встреч на вашей стороне.

**Что может сохраниться:** резервные копии сервера — до 14 дней, затем удаляются автоматически. Заметки, которые психолог вёл о встречах с вами, остаются у психолога как у самостоятельного специалиста **[юрист; проверить по коду, что удаляется каскадом]**. Сведения, которые мы обязаны хранить по закону (например, об оплатах, когда они появятся).

Удалить только историю разговоров, не удаляя аккаунт: «Профиль» → «Удалить историю».

## Ответы для Google Play Data safety

Все данные передаются по шифрованному каналу — **да**. Пользователь может запросить удаление — **да** (ссылка `/delete-account`).

| Тип данных | Собирается | Передаётся третьим лицам* | Обязательно | Цель |
| --- | --- | --- | --- | --- |
| Адрес эл. почты | да | нет | да | Функции приложения, управление аккаунтом, связь |
| Имя | да | нет | нет | Функции приложения |
| Сведения о здоровье (самочувствие, разговоры) | да | нет | нет | Функции приложения |

## Ответы для App Store «App Privacy»

- Data Linked to You: Contact Info (Email, Name), Health & Fitness (Health — самочувствие и разговоры), User Content (Messages, Audio, Photos, Other User Content), Identifiers (User ID, Device ID), Usage Data (Product Interaction).
- Data Used to Track You: **нет**.
- Цели для всех: App Functionality; для Usage Data — Analytics.

## Возрастной рейтинг

Приложение 18+ по условиям (Gemini API запрещает пользователей младше 18). В анкетах указать: тема ментального здоровья, медицинская/лечебная информация — нет (не даём медицинских советов), пользовательский контент и общение — **да** («Комнаты», чат с психологом). Ожидаемый рейтинг: Apple 17+, Google — «Для взрослых» / 18+.
