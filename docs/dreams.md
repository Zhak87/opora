# Дневник снов

Сделано по ТЗ «Дневник снов» v2.0, этап MVP для пространства пользователя.

## Что умеет

1. **Запись** (`/dreams/new`): текст или голос, подсказки-чипы, чувства с силой 1–5, тип сна, «что было накануне», герой комикса (4 пресета «Сновидца», без фото). Черновик хранится в браузере.
2. **Сценарий**: ИИ раскладывает сон на 3–4 кадра. Подпись кадра — только точная цитата человека (проверяется программно, иначе подпись убирается). Кадры можно править, удалять, переставлять, добавлять.
3. **Комикс**: кадры 4:5 в стиле «Лунная сказка», рисуются по одному. Подписи накладывает интерфейс. Метка ✦ «детали дорисованы», «нарисован символически», «перерисовать», «не рисовать этот кадр», оценка сходства 1–5.
4. **Размышление**: наблюдение по словам человека и 3–4 вопроса по цепочке «чувство → мысль → связь с днём → ресурс», поле «Мои мысли». Толкований нет: запрещённые формулировки отсекает постфильтр (`hasForbidden`), при срабатывании ИИ спрашивают ещё раз, затем берутся вопросы из банка.
5. **Дневник** (`/dreams`), удаление каскадом вместе с картинками.

Собеседник в разговоре сны тоже не толкует и может предложить шаг «Записать сон».

## Безопасность

- Кризисный стоп до всего остального: `looksLikeCrisis` + проверка ИИ, отличающая содержание сна от слов о реальной жизни. Комикс не рисуется, показываются контакты помощи.
- Смягчение тяжёлых образов: правила в промпте сценария, плюс вторая линия `looksHeavy` — такой кадр рисуется как место без фигур.
- Художнику уходит только английское описание сцены: без текста сна, имён и номера человека.
- Картинки лежат в закрытом хранилище `dreams`, папка на человека, ссылки подписанные.

## Кто рисует (`src/lib/dream-image.ts`)

| Вариант | Цена | Плюсы | Минусы |
|---|---|---|---|
| Cloudflare Workers AI, FLUX.1 schnell (по умолчанию) | бесплатно ~170 кадров 1024 px в сутки, дальше ~$0,0006 за кадр | чёткая картинка, без логотипа, запросы не хранятся | нет рисования по образцу и seed: героя держат одно описание и стиль, возможны мелкие расхождения; кадр квадратный, обрезается до 4:5 |
| Gemini Flash Image (`DREAM_IMAGES=gemini`) | около $0,04–0,07 за кадр | первый кадр идёт эталоном, герой и стиль совпадают; формат 4:5 | платно, бесплатного уровня нет |
| Pollinations | бесплатно | ключ не нужен | логотип на картинке, не больше 768 px, пауза 45 с между кадрами, результат доступен по ссылке любому — для личных снов не подходит |
| Together AI FLUX schnell Free | — | — | бесплатная точка больше не предлагается |

Смешанная схема (`DREAM_FALLBACK=gemini`, включена на сервере): сначала бесплатный Cloudflare, а если он не нарисовал кадр, рисует Gemini 3.1 Flash Image с готовым кадром как образцом героя. Платных кадров на весь сайт не больше `DREAM_GEMINI_PER_DAY` в сутки (10).

Лимиты на человека в скользящие сутки: `DREAM_BOARDS_PER_DAY` разборов сна (5, гостю 2) и `DREAM_PANELS_PER_DAY` кадров (12, гостю 4). Разбор — каждый удачный сценарий от ИИ, включая «Собрать заново»; учитывается строкой `provider = 'storyboard'` в `dream_generations`. Сохранить сон в дневник можно без лимита. Остаток виден на форме нового сна.

Скачивание: «Скачать кадр» отдаёт картинку через `GET /api/dreams/[id]/panels/[panel]?download=1` (права проверяет база). «Скачать комикс» собирает PNG 1600 px в браузере (`src/lib/dream-export.ts`): заголовок, кадры 2×2, подписи, подпись «Опора».

Анимации и звуки: кадр «проявляется» из тумана и медленно дышит, звёзды мерцают (всё отключается при «уменьшить движение»). Звуки синтезируются без файлов (`src/lib/dream-sounds.ts`): три ноты шкатулки на готовый кадр, «перелистывание» при скачивании и размышлении, кнопка «Музыка сна» (аккорды, ночной ветер, редкие ноты). Кнопка «Звуки» выключает короткие звуки, выбор запоминается.

## База

Миграция `0022_dreams.sql`: `dreams`, `dream_panels`, `dream_generations`, заделы `dream_shares` и `dream_access_log` (без интерфейса), хранилище `dreams`, новые события воронки.
